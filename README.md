# Northampton, MA plant map

This is an updated version of the dataset and code for my undergraduate Museums Concentration capstone project. It's an interactive map of plant species collected and observed in Northampton, Massachusetts, using specimens from the Smith College Herbarium and data from the Global Biodiversity Information Facility (GBIF). I georeferenced the 21 Smith College specimens, as well as 17 specimens from other herbaria with no coordinates or coordinates that didn't match their localities.

The original map can be viewed at https://flora-of-northampton.netlify.app/.
